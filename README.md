# Survival Schematic Brush

Survival Schematic Brush is an add-on for [Schematic Brush Reborn](https://github.com/eldoriarpg/SchematicBrushReborn).
Survival players pay for what they paste: the blocks of a schematic are taken from their inventory.

## Requirements

- Paper 1.21.11 or newer
- Java 25
- Schematic Brush Reborn 3 and FastAsyncWorldEdit

## Documentation

Installation, permissions and configuration are on [docs.eldoria.de](https://docs.eldoria.de/schematic-brush-reborn/survival).
